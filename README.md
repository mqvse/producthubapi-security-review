# ProductHubAPI Security Review

Security assessment of a RESTful API I built (C#, .NET, SQL) as part of a team project at university.

**Status:** In progress (started Oct 2026)

## Scope
- Authentication and authorisation
- Input validation and injection
- Rate limiting and error handling
- Checked against the OWASP API Security Top 10

## Deliverables
- [threat-model.md](threat-model.md): STRIDE threat model
- [findings.md](findings.md): issues found, severity, evidence
- `fixes/`: before and after for each fix
